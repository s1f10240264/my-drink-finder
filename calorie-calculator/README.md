# calorie note ♡
独立した静的Webアプリです。My Drink Finder本体のFlaskとは別にデプロイできます。

## ローカル確認
このフォルダの index.html をブラウザで開くか、フォルダ内で `python -m http.server 8001` を起動して `http://localhost:8001/` にアクセスします。

## 公開
Renderで **Static Site** を作成し、同じGitHubリポジトリを接続、Root Directoryを `calorie-calculator`、Publish Directoryを `.` に設定します（指定はRenderの設定画面で確認してください）。別のURLとサービスになります。必要ならこのフォルダだけを新規GitHubリポジトリにコピーしてデプロイできます。

## カロリー数値の範囲
過去の「冬のスタバ HOTドリンク低カロリーランキング」画像から15種類の Tall / Hot 通常レシピを転記。現行公式データでは未照合です。カスタム増減の数値は未登録で、自動的に架空値を割り当てません。ユーザーが確認した増減を入力すると基準カロリーに加減算します。入力が空白のカスタムが残る場合、合計は「確認待ち」です。公式栄養表を確認でき次第、data.jsを更新して対応するメニュー・サイズ・変更差分を増やせます。

公開前にモバイル表示、表示カロリー、著作権・商標・運営表記をチェックしてください。
