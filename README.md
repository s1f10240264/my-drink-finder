# きょう、なに飲む？ Ver.4（公開準備版）

スタバ風のドリンク選びを助ける非公式・個人制作アプリです。公式アプリではありません。

## 起動
1. ZIPを「すべて展開」する
2. app.py があるフォルダでPowerShellを開く
3. `python -m pip install -r requirements.txt`
4. `python app.py`
5. ブラウザで http://127.0.0.1:5000/ を開く

※以前のバージョンが起動中ならそのPowerShellで Ctrl+C で止めてください。

## 含まれる機能
- 4問の診断とTOP3
- 57のレシピ候補（25件の既存候補と32件の新規組み合わせ案）
- キーワード、温度、甘さ、コーヒー有無、候補の分類の絞り込み
- 予算、カロリー、追加料金0円の**確認済みデータのみ**を対象にした絞り込み
- お気に入り（同じブラウザ内）と注文文のコピー

## 重要：価格とカロリーの扱い
正確な金額・栄養情報を確認できていないため、現時点ではすべて「未確認」です。
予算・カロリー・無料カスタムを指定すると、数値未確認のレシピは表示されません。
公式の現行メニューとサイズを照合した後、app.py の `VERIFIED_DATA` に辞書形式で数値を追加できます。
例（架空の数値なのでそのまま使用しないでください）:
`VERIFIED_DATA = {'latte': {'price_yen': 999, 'calories_kcal': 999, 'extra_fee_yen': 999}}`
確認前の値を入れないでください。必要ならサイズ別のデータモデルへ拡張してください。

## 公開前のチェック
- レシピの注文可否・現行メニュー・サイズを公式情報や店頭で確認
- 価格・栄養情報の出典と確認日を記録
- 公式ロゴ・写真・商標利用や公認誤認を避ける
- `debug=True` を無効化し、適切な公開サーバーで実行
- スマホ表示、ブラウザの動作、注文文の表現をテスト

レシピ案は実際のTikTok投稿内容を1件ずつ確認したものではありません。投稿そのものの再現には、元動画のテキストやスクリーンショットが必要です。


## 友達にURLを送る（GitHub + Render）
1. GitHubでNew repositoryを作成し、PublicまたはPrivateを選びます。
2. `Add file` → `Upload files` で、このフォルダ内のファイル・`static`・`templates`をフォルダごとアップロード。**ZIPそのものはアップロードしないでください**。
3. RenderでNew → Web Service → GitHubのレポジトリを選択。
4. Pythonランタイム、Build Command は `pip install -r requirements.txt`、Start Command は `gunicorn --bind 0.0.0.0:$PORT app:app` に設定。
5. プランを確認し、Deploy完了後に表示される実際の `https://...onrender.com` を友達に共有。

`render.yaml` を使ったBlueprintからのデプロイも可能です。無料プランの有無・利用条件はRenderの画面で確認してください。無料プランではアイドル後の初回アクセスに時間がかかる場合があります。

**公開前に注意:** この版は57レシピ案のうち未検証カスタムを含みます。現在の販売状況や追加料金は正式に確認できていません。公開する場合は試作品と明示してください。公式サービスと誤認される表現・画像を避けてください。
